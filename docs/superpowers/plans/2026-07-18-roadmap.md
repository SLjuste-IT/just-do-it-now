# Roadmap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user lay out a plan as an ordered path of dated steps — "learn Linux" as step 1 → 2 → 3 — where finishing one step unlocks the next and dates cascade automatically.

**Architecture:** A roadmap is a project with `isRoadmap: true`; its steps are ordinary tasks chained through the existing `dependencies[]` field. Order is derived by walking that chain, never stored. Scheduling reuses `recomputeSchedule()`, changing only the inter-step gap from a flat constant to the prerequisite's `durationDays`.

**Tech Stack:** Vanilla JS in `index.html`, PocketBase (`appData` JSON blob — no schema change), precompiled Tailwind + CSS custom properties.

---

## Environment notes (read before starting)

**No test framework exists.** This is a single 7,600-line `index.html` with inline scripts; there is no pytest/jest/vitest and no test directory. Verification is done by driving the running app in a browser and asserting on real state — the same loop that caught the recurrence bugs earlier today. Each task's verification step gives the exact snippet to run.

Start the dev server once: `preview_start {name: "static"}` → http://localhost:4178. Reload after each edit (the file is served statically, no HMR).

**Not a git repo.** The "commit" step in the standard plan format cannot run. A timestamped backup of `index.html` exists (`index.html.bak-*`). Suggest `git init` before starting; otherwise checkpoint by copying `index.html` between tasks.

**Two IIFE scopes — this will bite you.** `index.html` has two independent script blocks:

| Block | Lines | Contains |
|---|---|---|
| A | 1726–4036 | `renderUpcoming`, `state`, `escapeHtml`, `toDateInput` |
| B | 4038–7606 | `normalizeTask`, `visibleTasksForMyList`, `recomputeSchedule`, `renderEverything`, `switchView` |

All new roadmap code goes in **Block B**. Anything Block A or inline `onclick=` markup needs must be assigned to `window.` explicitly, and Block A must call it defensively (`typeof window.fn === 'function' && window.fn(...)`). An unexposed function called by bare name from Block A throws `ReferenceError` and silently kills init.

**Two more constraints:**
- Tailwind is **precompiled**. A utility class not already in the build produces *no CSS*. All new styling uses plain CSS in the existing `<style>` block.
- Colors must come from the theme variables (`--surface`, `--surface-strong`, `--surface-soft`, `--line`, `--line-strong`, `--accent`, `--accent-2`, `--ink`). These are redefined per theme, so using them makes dark mode work automatically. Hardcoding slate/indigo collapses every dark theme into one.

## Task 2: Chain derivation and the lock predicate

**Files:** Modify `index.html` — new block in Block B, before `window.renderEverything`

- [ ] **Step 1: Add the roadmap module**

```js
  // ══════════════════════════════════════════════════════════════════════════
  //  ROADMAPS
  //  A roadmap is a project with isRoadmap:true; its steps are ordinary tasks
  //  chained through the existing dependencies[] field. Step order is DERIVED by
  //  walking that chain — never stored — so it can't drift from the real links.
  //  No schema change: isRoadmap / roadmapStart / durationDays ride in appData.
  // ══════════════════════════════════════════════════════════════════════════

  function isRoadmapProject(project) { return !!(project && project.isRoadmap); }

  function roadmapProjects() { return (state.projects || []).filter(isRoadmapProject); }

  // Walk the chain from the step with no prerequisite inside this roadmap.
  // Returns { chain, orphans }: orphans is anything the walk couldn't reach (a
  // hand-edited or partly-deleted chain), so no step is ever silently dropped.
  function roadmapChain(projectId) {
    const steps = (state.todos || []).filter(t => t.projectId === projectId);
    const ids = new Set(steps.map(t => t.id));
    const internalDeps = (t) => (t.dependencies || []).filter(d => ids.has(d));
    const chain = [];
    const seen = new Set();
    let cur = steps.find(t => internalDeps(t).length === 0);
    while (cur && !seen.has(cur.id)) {
      seen.add(cur.id);
      chain.push(cur);
      const prev = cur;
      cur = steps.find(t => !seen.has(t.id) && internalDeps(t).includes(prev.id));
    }
    return { chain, orphans: steps.filter(t => !seen.has(t.id)) };
  }

  // A step you can't act on yet: on a roadmap, not done, gated by a prerequisite
  // that isn't done. This is the single predicate the list filtering relies on.
  function isLockedRoadmapStep(task) {
    if (!task || task.completed) return false;
    const project = (state.projects || []).find(p => p.id === task.projectId);
    if (!isRoadmapProject(project)) return false;
    return (task.dependencies || []).some(id => {
      const dep = (state.todos || []).find(t => t.id === id);
      return dep && !dep.completed;
    });
  }

  function roadmapProgress(projectId) {
    const { chain, orphans } = roadmapChain(projectId);
    const all = chain.concat(orphans);
    return { done: all.filter(t => t.completed).length, total: all.length };
  }

  // Block A (renderUpcoming) and inline onclick= markup live outside this IIFE.
  window.isLockedRoadmapStep = isLockedRoadmapStep;
  window.roadmapChain = roadmapChain;
  window.roadmapProgress = roadmapProgress;
  window.isRoadmapProject = isRoadmapProject;
```

  async function createRoadmap(name, startDate, startTime, color) {
    name = String(name || '').trim();
    if (!name) { toast('Name required', 'Give your roadmap a name.', 'warning'); return null; }
    const start = startDate || toDateInput(new Date());
    const project = {
      id: generatePBId(), name, description: '',
      startDate: start, endDate: '',
      color: safeHex(color, '#3f888f'),
      priority: 'medium', status: 'active',
      isRoadmap: true, roadmapStart: start, roadmapStartTime: startTime || '09:00',
      createdAt: new Date().toISOString()
    };
    if (pb.authStore.isValid) {
      try {
        const record = await pb.collection('projects').create(projectToPBPayload(project, true));
        project.id = record.id; project.cloudSynced = true;
      } catch (err) { showPBError(err); return null; }
    }
    state.projects.unshift(project);
    state.selectedRoadmapId = project.id;
    await save(); renderEverything();
    return project;
  }

  async function addRoadmapStep(projectId, title, durationDays) {
    const project = (state.projects || []).find(p => p.id === projectId);
    if (!project) return null;
    title = String(title || '').trim();
    if (!title) { toast('Step needs a name', 'Describe what this step is.', 'warning'); return null; }
    const { chain } = roadmapChain(projectId);
    const last = chain[chain.length - 1];
    const step = normalizeTask({
      id: generatePBId(), title,
      // Seed on the roadmap's anchor: recomputeSchedule() only ever moves dates
      // FORWARD, so a step needs a floor to be pushed up from.
      dueDate: project.roadmapStart || toDateInput(new Date()),
      dueTime: project.roadmapStartTime || '09:00',
      categoryId: '', projectId,
      priority: 'medium', recurring: 'none', recurrence: { mode: 'none' },
      completed: false, notes: '', tags: [], collaborators: [],
      attachments: [], comments: [], subtasks: [],
      dependencies: last ? [last.id] : [],
      durationDays: Math.max(0, Math.round(Number(durationDays) || 1)),
      occurrenceCount: 0, createdAt: new Date().toISOString()
    });
    if (pb.authStore.isValid) {
      try {
        const record = await pb.collection('tasks').create(taskToPBPayload(step, true));
        step.id = record.id;
      } catch (err) { showPBError(err); return null; }
    }
    state.todos.push(step);
    await propagateAndPersistShifts(null);
    await save(); renderEverything();
    return step;
  }

  // Re-anchor a roadmap, then let the cascade lay the rest out. Every step is
  // reset to the anchor first because recomputeSchedule() only pushes forward —
  // without the reset, moving a start date EARLIER would do nothing.
  async function setRoadmapStart(projectId, startDate, startTime) {
    const project = (state.projects || []).find(p => p.id === projectId);
    if (!project) return;
    if (startDate) { project.roadmapStart = startDate; project.startDate = startDate; }
    if (startTime) project.roadmapStartTime = startTime;
    roadmapChain(projectId).chain.forEach(t => {
      if (t.completed) return;                 // don't rewrite history
      t.dueDate = project.roadmapStart;
      if (project.roadmapStartTime) t.dueTime = project.roadmapStartTime;
    });
    await propagateAndPersistShifts(null);
    await save(); renderEverything();
  }

  window.createRoadmap = createRoadmap;
  window.addRoadmapStep = addRoadmapStep;
  window.setRoadmapStart = setRoadmapStart;
```

      const cls = isDone ? 'is-done' : isCurrent ? 'is-current' : 'is-locked';
      const dur = Number(t.durationDays);
      const durText = Number.isFinite(dur) ? `${dur} day${dur === 1 ? '' : 's'}` : '';
      return `<div class="rm-step ${cls}">
        <div class="rm-dot">${isDone ? '<i class="fa-solid fa-check"></i>' : (i + 1)}</div>
        <div class="rm-card" onclick="openTaskModal('${t.id}')">
          <div class="flex items-center justify-between gap-2">
            <span class="rm-title font-bold text-sm truncate text-slate-900 dark:text-white">${escapeHtml(t.title || 'Untitled')}</span>
            ${isCurrent ? '<span class="rm-pill is-current">Next up</span>' : (isDone ? '' : '<span class="rm-pill"><i class="fa-solid fa-lock"></i></span>')}
          </div>
          <div class="rm-meta">${escapeHtml(formatDate(t.dueDate, t.dueTime))}${durText ? ' · ' + durText : ''}</div>
        </div>
      </div>`;
    }).join('');

    const orphanHtml = orphans.length ? `<div class="mt-5">
      <div class="text-[10px] font-bold uppercase tracking-wider text-slate-500 mb-2">Not on the path</div>
      ${orphans.map(t => `<div class="rm-card mb-2" onclick="openTaskModal('${t.id}')">
        <div class="font-bold text-sm truncate text-slate-900 dark:text-white">${escapeHtml(t.title || 'Untitled')}</div>
        <div class="rm-meta">Not linked into the sequence</div>
      </div>`).join('')}
    </div>` : '';

    detailEl.innerHTML = `
      <div class="flex flex-col sm:flex-row sm:items-center justify-between gap-3 mb-4">
        <div>
          <div class="font-bold text-lg text-slate-900 dark:text-white">${escapeHtml(project.name)}</div>
          <div class="rm-meta">${done} of ${total} done · ${pct}%</div>
        </div>
        <label class="text-xs text-slate-500 flex items-center gap-2">Starts
          <input type="date" class="ui-input !py-1 !px-2 !w-auto text-xs" value="${escapeHtml(project.roadmapStart || '')}"
                 onchange="setRoadmapStart('${project.id}', this.value, '')" />
        </label>
      </div>
      <div class="w-full h-1.5 rounded-full mb-5" style="background:var(--line)">
        <div class="h-1.5 rounded-full" style="width:${pct}%;background:var(--accent)"></div>
      </div>
      ${chain.length ? stepHtml : '<div class="text-sm text-slate-500 py-6">No steps yet — add the first one below.</div>'}
      ${orphanHtml}
      <form id="roadmapStepForm" class="grid grid-cols-1 sm:grid-cols-4 gap-2 mt-5 pt-5" style="border-top:1px solid var(--line)">
        <input id="roadmapStepTitle" type="text" class="ui-input text-sm sm:col-span-2" placeholder="Next step…" />
        <input id="roadmapStepDuration" type="number" min="0" step="1" value="2" class="ui-input text-sm" placeholder="Days" />
        <button type="submit" class="btn-secondary text-sm">Add step</button>
      </form>`;

    document.getElementById('roadmapStepForm').addEventListener('submit', async (e) => {
      e.preventDefault();
      const title = document.getElementById('roadmapStepTitle').value;
      const dur = document.getElementById('roadmapStepDuration').value;
      await addRoadmapStep(project.id, title, dur);
    });
  }

  function selectRoadmap(id) { state.selectedRoadmapId = id; renderRoadmapView(); }

  window.renderRoadmapView = renderRoadmapView;
  window.selectRoadmap = selectRoadmap;
```
